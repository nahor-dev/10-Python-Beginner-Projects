# 🐍 Python Beginner Projects

A collection of 10 beginner-friendly Python projects built to strengthen my programming fundamentals through hands-on practice. Each project focuses on solving a real-world problem while improving my understanding of core Python concepts.

## 📌 Projects

### 1. 🎯 Number Guessing Game

A command-line game where the player tries to guess a randomly generated number. The program provides hints after each guess and tracks the number of attempts.

### 2. 🔐 Password Generator

A command-line application that allows users to choose the password length and the types of characters to include. It then generates a random password based on the selected preferences.

### 3. ❓ Quiz Game

A quiz application that presents multiple-choice questions, checks the user's answers, keeps track of the score, and displays the final result at the end.

### 4. 📝 To-Do List

A command-line task manager that allows users to add, view, edit, and delete tasks, helping them organize their daily activities.

### 5. 📇 Contact Book

A simple contact management system where users can save, search, update, and delete contact information from the command line.

### 6. 🎓 Student Grade Manager

An application for recording student grades, calculating averages, and displaying performance summaries for multiple students.

### 7. 🏦 Banking System

A basic banking simulation that allows users to deposit money, withdraw funds, check their balance, and review transaction history.

### 8. 📚 Library Management System

A console-based application for managing a collection of books. Users can add books, search for them, borrow, return, and track their availability.

### 9. 💰 Expense Tracker

A personal finance application that records daily expenses, organizes them into categories, and calculates total spending.

### 10. ❌⭕ Tic-Tac-Toe

A two-player console version of the classic Tic-Tac-Toe game featuring turn-based gameplay, board updates, and automatic winner detection.

## 🚀 Getting Started

1. Clone the repository:

```bash
git clone https://github.com/nahor-dev/10-Python-Beginner-Projects.git
```

2. Navigate to any project folder:

```bash
cd 01-number-guessing
```

3. Run the project:

```bash
python main.py
```
